# V7 TNEX Digital Lending Decisioning Report

V7 extends the bank-grade V6 platform into a configurable, mobile-first decision engine serving Cash Loan, BNPL and Business Loan simulations. On 2,400 synthetic applications, the end-to-end orchestration p95 is below five seconds. Credit PD and fraud score remain independent inputs to a versioned product policy, preventing a single blended score from obscuring the decision rationale.

Alternative data is governed through explicit consent, freshness, ownership and fallback controls. The journey is measured from application start through disbursement or activation. Repeat customers receive explainable limit actions, while unresolved payment-posting exceptions automatically suppress collection reminders.

This is a portfolio simulation only. It is not an official TNEX model, does not use TNEX customer data and requires full independent validation, legal/compliance approval, live-data calibration and controlled deployment before any production use.
